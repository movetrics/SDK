## One vocabulary

Wherever the data comes from, it has the same shape: `t` in seconds from the FDT's own clock, `fx fy fz` in newtons, `mx my mz` in newton-metres, `cop_x cop_y` in metres from the plate centre, a list of `events` (sync edges, notes) and a list of `gaps` that is never hidden. [Names, units and axes](concepts/units-and-axes/).

## Why you can trust it

The Python, TypeScript and MATLAB clients pass the same shared test data, each the parts it uses. The centre of pressure agrees with Studio's own figures within 0.28 mm rms on real recordings, and C3D files land within 0.3 mm in the reader OpenSim uses (measured). The clients cannot send firmware, calibration or reset commands. Every page says what was measured, what was simulated and what has not been run yet; this version has not yet run against a real FDT. [Why you can trust it](concepts/tested/).

Free and open under Apache 2.0, at [github.com/movetrics/sdk](https://github.com/movetrics/sdk).
