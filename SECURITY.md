# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". Only the maintainers see the report.

Include:

- the SDK version or commit,
- the steps that reproduce the problem,
- what an attacker could do with it.

## What happens next

- We acknowledge the report and triage it.
- We ask for up to 90 days from the report to public disclosure. We tell you when a fix ships and, if you wish, credit you.
- We do not run a bounty programme.

## Scope

This repository holds the host SDK: the protocol description, the Python, TypeScript and MATLAB clients, the simulator, the test vectors and the documentation. Device firmware and the signing of device updates are outside this repository. Report problems with them through the same private channel.
